ChatGPT Watchdog 0.5.5
Windows 11 x64 portable application

WARNING: This app force-closes the ChatGPT Windows desktop app after computer
inactivity and an expired warning, even during active work. Unsaved work may
be lost. It does not detect active chats or tasks. Pause monitoring before
leaving important work unattended. Browser sessions are not supported.

GETTING STARTED
Extract all ZIP contents to a permanent folder and run ChatGPT-Watchdog.exe.
The .NET runtime is included; no installer or separate runtime is required.
First launch opens settings. Defaults: 45 minutes inactive, 120-second warning,
60-minute postponement. Review these and the startup preference before saving.
Startup at sign-in defaults to On and is registered when settings are saved.

Double-click the tray dog to open settings. Closing settings leaves monitoring
running. Use Pause monitoring for unattended work, or Exit watchdog to stop.
Pause and postponement reset when Watchdog restarts. Input cancels a countdown.
While Windows is locked, a countdown can expire without a visible warning.
Watchdog cannot operate during sleep or hibernation and does not wake Windows.

HELP AND DATA
Press F1 for Help. Settings > Open data folder opens settings, sounds and logs
stored separately under %LOCALAPPDATA%\ChatGPT Watchdog.
Exit before manually editing or copying settings. No chat content is collected.

UPDATES AND REMOVAL
Exit Watchdog and replace the supplied application files in the same folder.
Keep all license and notice files. Your separate data folder is preserved.
Before moving/removing the app, turn off startup and exit. If moved, enable
startup again from its new location. Remove the data folder separately if needed.
There is no automatic updater. The application is not digitally signed.
